# Сверка сметы и процентовок

Ручной выбор Excel подключён к основной программе по адресу http://127.0.0.1:8765. «Уточнить файл» и «Столбцы и режим объёмов» открывают выбор листов, диапазона и колонок по буквам с проверкой извлечения перед применением. Обычное открытие сохранённого проекта не перечитывает его файлы. Каталог запущенного приложения и версию импортёра можно проверить по `/api/runtime`. Подробности восстановления и проверки КС-2: `qa/EXCEL_RECOVERY_REPORT.md`.

Локальное приложение для сверки объёмов строительных работ. В интерфейсе загружаются Excel (.xlsx, .xls) из РИК. Сохранённые проекты продолжают работать. Денежные расчёты не выполняются.

## Как пользоваться

1. Запустите `run.bat`. Откроется http://127.0.0.1:8765.
2. Создайте сверку. На вкладке «Файлы» добавьте исходную смету Excel (.xlsx или .xls) и одну или несколько процентовок Excel.
3. Приложение определит таблицы и столбцы, прочитает работы и рассчитает результат. Если два столбца объёма одинаково подписаны, выберите нужный один раз для файла. Выбор запоминается для следующих файлов с такой же шапкой в этом проекте.
4. Посмотрите три группы результата и скачайте Excel. Нажмите на работу, чтобы увидеть, из каких процентовок получился объём.

Результат содержит ровно три группы:

- **ДОБАВЛЕННЫЕ**: новая работа или увеличение существующего объёма.
- **МИНУСОВЫЕ / ИСКЛЮЧЁННЫЕ**: уменьшение объёма или отсутствие выполнения в загруженных актах. Минус показывается отрицательным числом.
- **ФАКТИЧЕСКИ ВЫПОЛНЕННЫЕ**: сумма выполнения точно совпадает с исходной сметой.

Причина находится в правой колонке «Описание». Экспорт содержит те же три листа.

## Что распознаётся автоматически

Столбцы могут менять порядок. Поддерживаются многострочные и объединённые шапки, переносы текста, повторные заголовки, разделы, итоги, несколько таблиц Word и рабочих листов Excel. Таблица Word может продолжаться на следующей странице без повторной шапки при сохранении сетки. Объединённый по вертикали объём считается один раз; отдельные объёмы при объединённом названии сохраняются. Подписи, пустые строки и служебные копии справа исключаются из работ.

Главный признак — полное наименование позиции. Пробелы, регистр, переносы и незначащая пунктуация не создают новую позицию. Отличающиеся слова, материал, технология, размеры, марка и отсутствие уточнений означают отдельную позицию. Шифр не может объединить разные наименования: он помогает выбрать только между одинаковыми позициями. Работа и её материал сверяются отдельно. Если материал отсутствует в строках тендера, он попадает в «ДОБАВЛЕННЫЕ» с описанием «Новый материал». Отдельного раздела материалов нет.

Процентовки по умолчанию содержат **объём за текущий период**, который складывается. Накопительный режим нужно подтвердить для файла. В нём используется последнее значение; источники показывают приращения. Смешение текущего и накопительного режима по одной работе требует проверки.

## Когда требуется уточнение

Разные наименования автоматически становятся новыми позициями. «Проверить» остаётся при ошибках данных или различающихся единицах. Одинаковые позиции тендера с одной единицей складываются в общий объём. Накопительные объёмы, которые уменьшаются, и смешение режимов также требуют уточнения.

**Различие единиц измерения запрещает объединение даже при полном совпадении наименования или шифра.** Например, кг и т, м² и 100 м², м² и м³ — отдельные позиции. Строка процентовки учитывается отдельно в «Добавленные»: тип «Новая работа», описание «Требует уточнения». Ссылка открывает именно её в «Проверить», где можно оставить новую работу, исправить ошибочно прочитанные данные или не учитывать строку. Такая строка не блокирует расчёт тендерной позиции по нормальным совпадениям. Старые связи с переводом разных единиц больше не используются; исходные строки и история сохраняются. Новые позиции с нулевым объёмом в «Добавленные» не выводятся. Эквивалентные записи одной единицы (м², м2, кв.м) учитываются только при включённой настройке их равнозначности.

Объёмы считаются точными десятичными числами заново из активных файлов. Для каждой принятой строки проверяется, что исходный объём учтён целиком один раз. Количество и формула его расчёта не складываются. Масштаб единицы (например, 100 м²) сохраняется; разные масштабы автоматически не переводятся. Ошибочные, пустые и неподтверждённые объёмы не входят в результат. Пока файл не распознан, приложение не показывает ложные исключения. Одинаковый файл при повторной загрузке остаётся выключенным и не может включаться одновременно с прежней копией; дубли строк показываются как ошибки. Предварительный экспорт с нерешёнными позициями требует подтверждения.

Word должен содержать таблицы с текстом, а не картинки таблиц. Для неизвестной шапки доступны выбор столбцов и просмотр исходных строк. Старый дополнительный PDF-импорт сохранён для существующих проектов; OCR сканов не реализован. Лимиты: 50 000 строк, 150 колонок; загрузка через интерфейс — до 28 МБ.

XLSX использует сохранённые результаты формул. Простые формулы без кэша вычисляются ограниченным обработчиком: арифметика, ссылки внутри листа, SUM, AVERAGE, MIN, MAX, ABS, ROUND. Сложные, внешние и циклические формулы остаются ошибками; их нужно пересчитать и сохранить в Excel.

XLS читается локально библиотекой `xlrd` через отдельный адаптер `xls_reader.py`, затем использует ту же логику импорта и сверки. Выбор листов, диапазона и колонок, проверка извлечения и применение работают в существующем окне Excel. XLS использует только сохранённые значения формул, не пересчитывает их и не определяет их давность: изменённый файл нужно пересчитать и сохранить в Excel перед загрузкой. Ошибки ячеек не превращаются в нулевые объёмы. Защищённые паролем и повреждённые файлы отклоняются. HTML с расширением `.xls` нужно сначала сохранить в Excel как настоящий XLS или XLSX. После установки зависимостей чтение обоих форматов работает без интернета.

НсП и НДС исключаются по точному названию при отсутствии номера и шифра и при пустой единице или `%`. Процент не используется как объём. Номер позиции не обязателен для остальных работ; неполные позиции остаются для проверки. Настоящие итоги имеют финансовую структуру: название «Итоговая проверка…» само по себе не исключает работу. Один включённый лист нельзя импортировать дважды. Ошибки выбранных ячеек XLSX требуют проверки, а ручные решения не могут превратить начисление, итог или раздел в работу. Чтение продолжается после итогов в следующем разделе.

Предупреждения файла показываются сразу. Обновлённые правила действуют при проверке и применении импорта; сохранённые проекты автоматически не перечитываются. Для старого импорта откройте «Посмотреть строки» → «Столбцы и режим объёмов», проверьте извлечение и примените его. При прежних листах, диапазоне, колонках и режиме ручные решения сохраняются; решение для служебной строки не допускается к расчёту.

## Запуск и хранение

На этом компьютере `run.bat` использует установленную среду Python. Для другого компьютера нужен Python 3.11+ и зависимости из `requirements.txt`:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

Все данные хранятся локально в `data`: SQLite, исходные файлы, решения и журнал. Для резервной копии остановите приложение и скопируйте эту папку. Для замены сметы загрузите новую и нажмите «Использовать эту смету». Старый файл сохраняется. Для замены процентовки выключите прежний акт и загрузите новый.

Кнопка «Удалить проект» рядом с выбором проекта убирает его из списка после подтверждения. Через «Удалённые» можно восстановить проект с исходными файлами, настройками и решениями.

`app.py` — API; `importing.py` и `docx_reader.py` — чтение таблиц; `matching.py` — строгие правила наименования и единиц; `core.py` — сверка на Decimal; `exporting.py` — три листа Excel; `storage.py` — сохранение проектов. Приложение работает только на 127.0.0.1.

## Проверки

```powershell
python -m unittest discover -s tests -v
```

Проверяются приоритет наименований над кодами, материалы, точность объёмов и экспорта, суммы актов, три группы, неоднозначности, сохранение решений, совместимость старых Word-проектов, все 120 перестановок пяти столбцов, объединения, повторные шапки, несколько таблиц, дубли, формулы и выбор объёма для файла. Демонстрационные Excel-файлы находятся в `demo`; `demo.py` создаёт отдельный демонстрационный проект.
